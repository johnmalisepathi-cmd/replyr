# ArtCraft Studio

A browser-based digital art, painting & colouring book creator built with React, Vite, and Tailwind CSS.

## Features

- **Free Draw mode** — paint on a blank canvas with a brush, eraser, fill bucket, and line/rectangle/circle shape tools.
- **Colouring Book mode** — pick from a gallery of ready-made line-art templates (flower, mandala, butterfly, cottage, heart wreath) and fill them in with the colour picker or fill bucket.
- Adjustable brush size and opacity, a quick-pick colour palette plus a custom colour picker.
- Undo / redo history, clear canvas, and export your artwork as a PNG.

## Getting started

```bash
cd art-creator
npm install
npm run dev
```

Then open the printed local URL in your browser.

## Build

```bash
npm run build
npm run preview
```
